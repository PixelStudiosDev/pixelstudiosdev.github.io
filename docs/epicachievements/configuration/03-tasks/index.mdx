# Tasks

EpicAchievements includes built-in tasks for common Minecraft actions, as well as plugin hooks. Browse the task groups below to find each task and its supported conditions. See [Conditions](/epicachievements/configuration/conditions) for details about condition types.

| Task | Description | Supported conditions | Required MC version | Requires Paper |
|---|---|---|---:|:---:|
| `BREAK` | Break a block | `blocks`, `crop_age` | 1.8 | — |

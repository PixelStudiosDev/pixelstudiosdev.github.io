# Conditions

Conditions add requirements that must be met for an achievement to progress. Their availability depends on the task type or plugin integration.

:::info
Lists of entities, items, blocks, and other values are treated as **whitelists** by default. To treat the listed values as a **blacklist**, add `blacklist: true`.

```yaml
conditions:
  - type: items
    items:
      - "NETHERITE_INGOT"
    blacklist: true
```
:::

:::tip
Most condition types support **wildcards**:

```yaml
conditions:
  - type: items
    items:
      - "*_PICKAXE" # Matches all types of pickaxes
```
:::

## Global conditions

These conditions are available for all achievement tasks.

| Condition | Description | Required arguments |
|---|---|---|
| `biomes` | Allowed biomes | `biomes` |
| `game_modes` | Allowed game modes | `game-modes` |
| `has_equipped` | Requires the player to have an item equipped | `items` |
| `has_held` | Requires the player to hold an item | `items` |
| `has_inventory_open` | Checks whether the player has an inventory open. The player's own inventory is excluded. | `value` (`true`/`false`) |
| `has_item` | Requires the player to have an item in their inventory | `items` |
| `is_flying` | Checks whether the player is flying | `value` (`true`/`false`) |
| `is_sneaking` | Checks whether the player is sneaking | `value` (`true`/`false`) |
| `is_sprinting` | Checks whether the player is sprinting | `value` (`true`/`false`) |
| `riding_entity` | Requires the player to ride an entity | `entities` |
| `worlds` | Allowed worlds | `worlds` |

## Task-specific conditions

These conditions are available only for supported task types. See [Tasks](/epicachievements/configuration/tasks) for the supported conditions for each task.

| Condition | Description | Required arguments |
|---|---|---|
| `blocks` | A list of block materials | `blocks` |
| `crop_age` | Limits the crop growth stage to a specific age or `MAX` | `age` |
| `damage_causes` | A list of [damage causes](https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/event/entity/EntityDamageEvent.DamageCause.html) | `causes` |
| `entities` | A list of entities. **MythicMobs** is supported with `mythicmobs:<id>` or `mm:<id>`. | `entities` |
| `is_hostile` | Checks whether an entity is hostile | `value` (`true`/`false`) |
| `items` | A list of items | `items` |
| `potion_types` | A list of [potion types](https://hub.spigotmc.org/javadocs/spigot/org/bukkit/potion/PotionType.html) | `types` |

## Plugin hook conditions

These conditions are provided through integrations with other plugins.

| Plugin | Condition | Description | Required arguments |
|---|---|---|---|
| [CustomFishing](https://polymart.org/resource/customfishing.2723) | `custom_fishing_loot` | A list of loot IDs | `loot` |
| [PlaceholderAPI](https://www.spigotmc.org/resources/6245/) | `placeholder` | Evaluates a PlaceholderAPI placeholder | [`placeholder`, `value`, `operator`](./tasks/placeholder#placeholders-that-output-text) |
| [Vault](https://www.spigotmc.org/resources/34315/) | `vault` | Checks whether a player has a certain balance | `balance` |
| [WorldGuard](https://dev.bukkit.org/projects/worldguard) | `regions` | Checks whether a player is within a region | `regions` |
